# Spots – Responsive Social Photo App

## 📌 Project Description

**Spots** is a responsive web application that allows users to share photos, like posts, and customize their profile.  
The app communicates with a remote API to load user data, persist likes, update avatars, and manage cards in real time.

Built using modern front-end architecture, Spots is optimized for desktop, tablet, and mobile devices with smooth UI interactions and scalable structure.

---

## ⚙️ Functionality

Users can:

- View profile information loaded from the API
- Edit profile name and description
- Update profile avatar
- Add new photo cards
- Delete their own cards (with confirmation)
- Like and unlike cards
- Preview images in a modal
- Use fully validated forms
- Experience responsive layouts across screen sizes

All data persists after refresh through API integration.

## 🧠 Techniques & Best Practices

- Modular JavaScript structure
- Reusable modal open/close logic
- Single Api class instance
- Universal form validation system
- Clean separation of concerns
- Responsive grid layout
- Accessibility-friendly interactions
- Hover states on interactive elements
- Loading states on form submission
- No innerHTML data injection
